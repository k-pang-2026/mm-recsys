# 게시 직전 검증 범위

PDF 구현·리소스 리팩터링 검증 뒤 추가한 대시보드 KST·소수 한 자리 표시를 포함한다.
`submission/checks.json`은 현재 소스의 전체 테스트·mypy·의존성·실제 API·기존 full 근거를 다시 검사한 결과다.
`dashboard/`는 실제 Chromium 여섯 탭과 표시 정밀도 검증, 19개 관련 테스트의 원본이다.

`runtime_sources.json`은 실행 중 API·대시보드 및 simulator 이미지의 파일을 직접 읽어 비교한다.
simulator는 소스 확인용 일회 컨테이너이며 자동 재학습을 새로 실행하지 않았다.
`fresh_reproduction_full.json`은 이전 빈 경로 준비 실행을 그대로 연결하고 현재 배포 소스 검증을 덧붙인다.
표시 변경으로 학습·데이터·평가 소스가 바뀌지 않았음을 확인했으며 모델 학습·full 품질 측정은 반복하지 않았다.

이전 테스트·품질·실패 근거는 상위 폴더에 보존한다. A/B의 음의 효과, 실제 CT RETAINED,
별도 통제 승격·롤백, 노출 한 건의 전후 차이는 기존 보고서의 제한을 그대로 적용한다.
원격 공개·CI·병합 상태와 SHA는 해당 GitHub PR 기록으로 확인한다.
